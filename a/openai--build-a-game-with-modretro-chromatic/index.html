Codex와 ModRetro Chromatic으로 레트로 휴대용 게임 만들기

Building a retro handheld game with Codex and ModRetro Chromatic

Codex용 ModRetro Chromatic 플러그인을 사용하면 상상하는 어떤 게임이든 만들어 ModRetro Chromatic에서 플레이할 수 있습니다.

Using the ModRetro Chromatic plugin for Codex, you can build any game you can imagine and play it on a ModRetro Chromatic.

아이폰에는 미안하지만, 역대 가장 상징적인 휴대용 기기는 Game Boy일지도 모릅니다. 한 세대의 아이들은 버스에서 쿠파 병사(Koopa)를 밟고, 통신 케이블로 친구들과 포켓몬 대결을 벌였으며, 이 모든 것을 주머니에 들어가는 기기 하나로 즐겼습니다. 정확히는 백팩의 주머니에 들어가는 크기였습니다.

오늘날에는 강력한 코딩 모델과 Codex 같은 도구 덕분에 나만의 게임을 만드는 일이 그 어느 때보다 쉬워졌고, 제 생각에는 더 재미있어졌습니다. 하지만 Game Boy Color 같은 전용 하드웨어에서 게임이 돌아가는 경험에는 다른 무엇으로도 대체하기 어려운 특별함이 있습니다. 그래서 Codex용 ModRetro 플러그인으로 Game Boy Color 게임을 만들고 Chromatic에서 플레이할 수 있게 되었다는 소식을 전하게 되어 정말 기쁩니다.

스페셜 에디션 ModRetro Chromatic 주문하기

바로 어떻게 작동하는지 살펴보겠습니다.

플러그인 설치

  1. ChatGPT 데스크톱 앱의 ChatGPT 드롭다운에서 Codex를 선택합니다.
  2. Plugins를 열고 ModRetro Chromatic을 검색합니다. ModRetro가 제공하는 ModRetro Chromatic Plugin을 선택한 후 Install을 클릭합니다.
  3. 로컬 프로젝트 폴더를 열고 채팅을 시작합니다. @를 입력하고 플러그인을 선택하면 Codex가 어떤 도구를 사용해야 하는지 알 수 있습니다.
  4. Codex에 플러그인을 설정하고 누락된 빌드 도구가 있는지 확인해 달라고 요청합니다. 그러면 컴퓨터에서 첫 번째 게임을 빌드하고 플레이할 수 있습니다.

첫 번째 게임 프롬프트 작성

Codex 채팅에서 플러그인을 선택한 상태로, 만들고 싶은 게임을 설명합니다. 영상을 따라 해 보려면 다음 예시 프롬프트를 사용하십시오.

Lodge Podge라는 이름의 탑다운 어드벤처 게임을 만들어 주세요. 픽셀 아트 비버가 작은 나무를 갉아 쓰러뜨려 막대기를 모으고, 이를 이용해 레벨 중앙에 롯지(lodge)를 짓는 게임입니다.

다음으로 Codex에 게임을 빌드하고 미리보기를 열어 달라고 요청합니다. GB Studio 프로젝트 폴더에서 다음 파일의 위치를 알려 달라고 요청할 수도 있습니다.

  • GB Studio에서 .gbsproj 파일을 열어 장면(scene), 액터(actor), 이벤트를 편집합니다.
  • assets/에서 프로젝트에 사용된 스프라이트 시트, 배경, 오디오를 확인합니다.
  • 컴파일된 .gbc 파일을 에뮬레이터에서 실행하거나 카트리지에 설치합니다.

그다음에는 몇 판 플레이해 보고, 게임을 더 재미있게 만들 방법을 Codex에 알려 주십시오. Lodge Podge에서는 비버를 더 통통하게(최대한 귀엽게) 만들고, 롯지를 지으려면 막대기뿐 아니라 진흙과 나뭇잎도 필요하도록 해 달라고 요청했습니다.

플러그인 구성

ModRetro Chromatic 플러그인에는 모델이 사용자를 대신해 활용할 수 있는 개발자 도구가 들어 있습니다.

캐릭터 애니메이션

Codex에 스프라이트 시트를 만들고 프레임을 나란히 보여 달라고 요청합니다. 애니메이션을 수정하려면 바꾸고 싶은 포즈나 방향을 지정한 후, Codex에 미리보기를 다시 만들어 달라고 요청합니다.

플레이어가 걸어 다닐 수 있는 맵 만들기

Codex에 장면의 배경과 충돌 맵(collision map)을 나란히 보여 달라고 요청합니다. 충돌 맵은 어떤 타일이 이동을 막는지 표시합니다. 배경을 보고 원하는 영역을 특정한 후, 어떤 타일을 이동 불가 또는 이동 가능으로 표시할지 Codex에 알려 주십시오.

Codex에서 ROM 플레이

Codex에 내장 브라우저에서 게임 미리보기를 열어 달라고 요청합니다. Game Boy의 방향 패드(D-pad)에는 방향키를, A에는 Z를, B에는 X를, Start에는 Enter를 사용합니다. 에뮬레이터 위의 툴바에서 일시 정지하거나 다시 시작할 수 있습니다.

변경하고 싶은 부분 가리키기

미리보기 툴바에서 Annotate game을 선택한 후 게임 화면을 클릭해 프레임을 고정합니다. 바꾸고 싶은 스프라이트, 타일 또는 영역을 선택하고 수정 내용을 설명합니다. Resume game을 선택하면 에뮬레이터로 돌아갑니다. Codex가 변경을 마치면 ROM을 다시 빌드하고 미리보기를 다시 열어 달라고 요청합니다.

Codex로 일련의 동작 테스트

채팅에서 에뮬레이터를 직접 제어할 수도 있습니다. Codex에 ROM을 실행하고, 버튼 입력을 순서대로 보내고, 각 단계 후에 프레임을 캡처해 달라고 요청합니다. 프레임을 나란히 보여 달라고 하면 한눈에 비교해 검토할 수 있습니다.

GB Studio에서 편집

GB Studio는 Game Boy 게임을 만들기 위한 비주얼 에디터입니다. 프로젝트의 .gbsproj 파일을 열고 Game World를 선택합니다. 내비게이터에서 장면을 선택하면 사이드바에 해당 장면의 속성이 표시됩니다. 액터를 새로운 타일로 드래그하거나, 장면에서 직접 충돌을 편집할 수 있습니다. 프로젝트를 저장한 후 Codex 채팅으로 돌아가 다시 빌드하고 미리보기를 열어 달라고 요청합니다. 장면에 대한 GB Studio 가이드에서 배경, 액터, 트리거가 서로 어떻게 맞물리는지 설명합니다.

그 외 개발 옵션

  • GB Studio 게임 확장하기. 기본 제공 이벤트로 원하는 메커니즘을 구현할 수 없다면, GB Studio의 가상 머신 언어인 GBVM으로 커스텀 이벤트를 추가하거나 C로 엔진을 확장할 수 있습니다. 자세한 내용은 GB Studio 플러그인 가이드를 참고하십시오.
  • GBDK-2020으로 C 게임 작성하기. ModRetro 플러그인은 GBDK의 lcc 컴파일러로 독립 실행형 C 코드를 컴파일할 수 있습니다. GBDK의 Game Boy API를 사용하면 버튼, 스프라이트, 타일, 팔레트를 다룰 수 있습니다. Codex에게 D-pad 입력을 읽고 스프라이트 하나를 움직이는 게임 루프부터 만들어 달라고 요청해 보십시오.
  • 자체 엔진 작성하기. Codex에게 게임 루프, 스크롤링, 충돌 처리를 처음부터 구현하도록 맡길 수 있습니다. 어셈블리 프로젝트라면 RGBDS와 같이 별도로 설치한 툴체인으로 ROM을 빌드하십시오. 그런 다음 생성된 .gb 또는 .gbc 파일을 플러그인에 전달하여 검사하고 플레이 테스트를 진행합니다.

기기에 배포하기

Chromatic, 호환되는 재기록 가능 홈브류 카트리지, USB 데이터 케이블이 필요합니다. 휴대용 기기에 연결할 컴퓨터에서 ModRetro 퀵스타트를 따라 펌웨어를 업데이트하고 개발자 모드(Developer Mode)를 활성화하십시오.

  1. 카트리지를 삽입하고 Chromatic을 컴퓨터에 연결한 다음, 로컬 Codex 채팅에서 게임 미리보기를 엽니다.
  2. Install on Chromatic을 선택하고 연결된 기기를 지정한 뒤 Install을 클릭합니다. 확인 메시지를 주의 깊게 읽으십시오. 새 ROM을 기록하면 해당 카트리지에 있던 게임이 삭제되며, 저장 데이터도 삭제될 수 있습니다. 설치 프로그램은 카트리지를 백업하지 않습니다.
  3. 준비가 되면 Confirm Install을 선택합니다. 플러그인이 성공을 알릴 때까지 케이블을 연결한 상태로 두었다가, 성공하면 Chromatic에서 게임을 실행합니다.

"The Power of Science is Staggering!"

Codex용 ModRetro 플러그인을 사용하면 프롬프트만으로 오리지널 Game Boy Color 게임을 만들 수 있으며, 활발한 GBC 홈브류 개발 생태계의 모든 도구를 활용할 수 있습니다. 정말 정말 재미있을 것입니다. ModRetro Chromatic을 직접 주문하고 ModRetro의 다른 프로젝트도 살펴보십시오. 즐거운 Game Boy 해킹이 되시길 바랍니다!

With all due respect to the iPhone, the Game Boy might be the most iconic handheld device of all time. A generation of kids stomped Koopas on the bus and battled their friends in Pokémon over a link cable, all on a device that fit in your pocket. Or at least a pocket of your backpack.

With today’s powerful coding models and tools like Codex, building your own games has never been easier (or, in my opinion, more fun). But there’s something special about a game running on purpose-built hardware, like the Game Boy Color, that’s hard to replace. That’s why I am sooo excited to share that the ModRetro plugin for Codex lets you build Game Boy Color games and play them on a Chromatic.

Order the special edition ModRetro Chromatic.

Let’s jump right in and explain how it works.

Install the plugin

  1. In the ChatGPT desktop app, select Codex from the ChatGPT dropdown.
  2. Open Plugins and search for ModRetro Chromatic. Select ModRetro Chromatic Plugin by ModRetro, then click Install.
  3. Open a local project folder and start a chat. Type @ and choose the plugin so Codex knows which tools to use.
  4. Ask Codex to set up the plugin and check for any missing build tools. You can build and play your first game on your computer.

Prompt your first game

With the plugin selected in your Codex chat, describe the game you want to build. To follow along with the video, use this example prompt.

Build a top-down adventure game called Lodge Podge where a pixel beaver must chew down small trees to gather sticks to build a lodge in the center of the level.

Next, ask Codex to build the game and open the preview. You can also ask it to point you to these files in your GB Studio project folder.

  • Open the .gbsproj file in GB Studio to edit scenes, actors, and events.
  • Look in assets/ for the sprite sheets, backgrounds, and audio used by the project.
  • Run the compiled .gbc file in an emulator or install it on a cartridge.

From there, play a few rounds and tell Codex what would make the game more fun. In Lodge Podge, I asked Codex to make the beaver chonkier (for maximum cuteness) and to require mud and leaves as well as sticks to build the lodge.

What’s in the plugin

The ModRetro Chromatic plugin contains developer tools the model can use on your behalf.

Animate a character

Ask Codex to create a sprite sheet and show you the frames side by side. To revise the animation, identify the pose or direction you want to change, then ask Codex to rebuild the preview.

Build a map the player can walk through

Ask Codex to show you a scene’s background and collision map side by side. The collision map marks which tiles block movement. Use the background to identify the area you mean, then tell Codex which tiles to mark as blocked or walkable.

Play the ROM in Codex

Ask Codex to open the game preview in its built-in browser. Use the arrow keys for the Game Boy’s D-pad, Z for A, X for B, and Enter for Start. Use the toolbar above the emulator to pause or resume.

Point to the part you want to change

Choose Annotate game in the preview toolbar, then click the game display to freeze a frame. Select the sprite, tile, or area you want to change and describe the edit. Choose Resume game to return to the emulator. After Codex makes the change, ask it to rebuild the ROM and reopen the preview.

Have Codex test a sequence of moves

You can also control the emulator from chat. Ask Codex to run the ROM, send a sequence of button presses, and capture a frame after each step. Ask for the frames side by side so you can inspect them together.

Edit in GB Studio

GB Studio is a visual editor for building Game Boy games. Open your project’s .gbsproj file and choose Game World. Select a scene in the navigator to see its properties in the sidebar. You can drag an actor to a new tile or edit collisions directly on the scene. Save the project, then return to your Codex chat and ask it to rebuild and open the preview. The GB Studio guide to scenes explains how backgrounds, actors, and triggers fit together.

Other development options

  • Extend a GB Studio game. If the built-in events don’t cover a mechanic, you can add a custom event in GBVM, GB Studio’s virtual-machine language, or extend the engine in C. See the GB Studio plugin guide.
  • Write the game in C with GBDK-2020. The ModRetro plugin can compile standalone C with GBDK’s lcc compiler. GBDK’s Game Boy APIs give you access to buttons, sprites, tiles, and palettes. Ask Codex to start with a game loop that reads the D-pad and moves a single sprite.
  • Write your own engine. You can have Codex implement the game loop, scrolling, and collisions from scratch. For an assembly project, build the ROM with a separately installed toolchain such as RGBDS. Then give the resulting .gb or .gbc file to the plugin to inspect and playtest.

Deploy to device

You’ll need a Chromatic, a compatible rewritable homebrew cartridge, and a USB data cable. Follow ModRetro’s quickstart to update the firmware and activate Developer Mode using the computer you’ll connect to the handheld.

  1. Insert the cartridge, connect the Chromatic to your computer, and open the game preview in your local Codex chat.
  2. Choose Install on Chromatic, select your connected device, and click Install. Read the confirmation carefully. Writing the new ROM erases the game on that cartridge and can erase its saves. The installer doesn’t back up the cartridge.
  3. Choose Confirm Install when you’re ready. Leave the cable connected until the plugin reports success, then start the game on the Chromatic.
